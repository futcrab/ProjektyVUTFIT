Install steps:
1. Download and install FitGraphics framework from: https://git.fit.vutbr.cz/imilet/FitGraphics
2. Add and replace contents from SourceFiles directory into /FitGraphics/src/student
3. Run FitGraphics from Visual Studio Solution and go to student -> project

Control:
Use GUI and mouse to control the visuals
Hold left mouse button + movement to move the object and resetModelMatrix button to transport it back to original position
